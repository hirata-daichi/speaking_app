# English Speaking Feedback

日本語話者向けの英語スピーキング練習アプリです。質問に英語で答え、音声認識の結果を確認・修正してから、文法・語彙・回答内容のフィードバックを受けられます。

評価対象は文字起こしされた英文です。発音、イントネーション、音響的な流暢さは評価しません。AIの点数と添削は学習の目安であり、正確性を保証するものではありません。

**機能**

- レベル・トピック別の固定問題と、Ollamaによる質問生成。直前と同じ問題を避けます。
- マイク録音、音声アップロード、サンプル音声による練習。
- Whisperで文字起こしし、認識内容を修正してから採点。
- 文法の修正と任意の表現提案を分けて表示。
- 構造化されたLLM出力の検証と、添削内容の追加確認。整合性を確認できない点数や修正提案は表示を控えます。
- 接続失敗時も文字起こしを保持。模範回答だけの再取得も可能。
- 同じ質問への再挑戦、前後比較、セッション内の学習履歴（最大50件）。
- 処理状況の表示と、Ollama・使用モデルの接続確認。

**セットアップ**

Python 3.12で確認しています。既存の環境を更新する場合も、依存関係をインストールし直してください。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

検証環境の依存一式を再現する場合は `requirements.lock.txt` を使えます。固定一覧はmacOS / Python 3.12で確認したものです。

```bash
python -m pip install -r requirements.lock.txt
```

Ollamaを起動し、使用するモデルを準備します。

```bash
ollama serve
```

別のターミナルで実行します。Ollamaのアプリ等で既に起動している場合、`ollama serve` は不要です。

```bash
ollama pull qwen2.5:7b-instruct
```

**起動と使い方**

```bash
source .venv/bin/activate
python app.py
```

表示されたローカルURLをブラウザで開きます。標準では8960〜9059の空きポートを使います。

1. レベルとトピックを選び、「新しい質問」を押します。
2. 回答を録音するか、音声ファイルを選びます。
3. 「文字起こし」を押し、認識ミスがあれば修正します。
4. 「この文章を採点」を押します。
5. 「同じ質問に再挑戦」で回答し直し、比較欄で前回との差を確認します。

「サンプルで練習」を押すと、週末について答える合成音声が読み込まれます。録音なしで文字起こしから試せます。

**設定と保存範囲**

| 環境変数 | 標準値 | 内容 |
| --- | --- | --- |
| `OLLAMA_MODEL` | `qwen2.5:7b-instruct` | インストール済みの採点モデル |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollamaの接続先 |
| `WHISPER_MODEL` | `base` | 音声認識モデル |
| `LLM_TIMEOUT_SECONDS` | `120` | LLMの読み取りタイムアウト（秒） |
| `GRADIO_SERVER_PORT` | 自動 | 固定する場合は1〜65535 |

回答は2分・20MB、文字起こしは6000文字を上限としています。履歴はブラウザごとのセッション内で保持し、データベース等には永続保存しません。音声の一時キャッシュは作成から24時間経過後、1時間ごとの処理で削除します。

初回のWhisper利用時はモデルを取得するため、ネット接続と準備時間が必要です。既存のキャッシュだけで検証する場合は `HF_HUB_OFFLINE=1` を指定できます。

**テスト**

LLMやWhisperモデルをダウンロードせず、自動テストを実行できます。

```bash
python -m unittest discover -s tests -v
python -m pip check
```

2026年10月22日の確認では、自動テスト57件、ローカルモデルを使った評価例10件、合成音声による一連の処理を検証しています。確認範囲と制約は下記の説明を参照してください。

既存のローカルモデルを使う追加確認は、明示的に次のコマンドで実行します。

```bash
python scripts/check_quality.py --output /tmp/english-speaking-quality-results.json
python scripts/check_audio_flow.py
```

前者は正しい英文、典型的な誤り、質問と無関係な回答など10例を比較します。後者はサンプル音声のアップロード・文字起こし・文章の修正・採点・再挑戦・容量制限・無音の処理を、Gradioの入出力処理を通して確認します。合成音声での試験であり、実際のマイク操作や様々な話者の認識精度を保証するものではありません。

依存監査は検証環境に `pip-audit` を導入して実行できます。

```bash
python -m pip install pip-audit
python -m pip_audit --progress-spinner off
```

PyAVはWhisperとのAPI互換性のため17.1.0に固定しています。更新する場合は実音声の結合テストも実行してください。

2026年10月22日の検証では、Gradioが要求する `Pillow<13` と、Pillowの修正版13.0.0が競合し、Pillowに既知の脆弱性の指摘が残っています。このアプリは画像処理機能を使いませんが、依存監査が無警告になったわけではありません。動作するサーバーを外部へ公開する際は、上流の対応状況を再確認してください。

**構成**

- `app.py`：画面とイベント処理
- `feedback.py`：音声認識、Ollama通信、出力検証、添削の整合性確認
- `practice.py`：質問・回答・履歴の管理と結果表示
- `question_bank.py`：固定質問データ
- `tests/`：自動テストと評価用の例文
- `scripts/`：実モデルを使う追加確認
